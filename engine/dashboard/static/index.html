The engine works fully without AI, using rules. Adding your own API key makes it read what is actually said to judge context and payoff, rank clips against each other, and write hooks and captions specific to each clip.
Your key is saved only on this computer, in config/secrets.env, and is never shown again after saving. A typical stream costs cents with Sonnet-class models; Haiku-class models are cheaper. The log shows how many tokens each run used.
